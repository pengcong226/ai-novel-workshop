## 1. @xenova/transformers

### 当前状态

| 项目 | 值 |
|------|-----|
| 当前版本 | `^2.17.1` |
| npm latest | `2.17.2` |
| 最后发布日期 | 2024-05-29 |
| 许可证 | Apache-2.0 |

### 版本分析

当前锁定范围 `^2.17.1` 可解析到 `2.17.2`，这是 `@xenova/transformers` 的最终版本。该包自 2024 年 5 月后已**停止发布新版本**。

### 重命名与迁移

`@xenova/transformers` 已正式迁移为 **`@huggingface/transformers`**：

- 原作者 (xenova / Joshua Lochner) 已成为 Hugging Face 官方团队成员
- `@huggingface/transformers` 最新稳定版为 **`4.2.0`**（2026-04-22 发布）
- 维护者已包含 xenova 本人，说明官方包是项目的正式延续

#### @huggingface/transformers 版本历程

| 版本 | 发布日期 |
|------|----------|
| 3.x 系列 | 2024 年中起 |
| 4.0.0 | 2026-03-30 |
| 4.1.0 | 2026-04-15 |
| 4.2.0 | 2026-04-22 |

#### 迁移注意事项

1. **包名变更**: `@xenova/transformers` -> `@huggingface/transformers`
2. **导入路径变更**: 所有 `import { ... } from '@xenova/transformers'` 需改为 `import { ... } from '@huggingface/transformers'`
3. **依赖变更**: 新版本依赖 `onnxruntime-web: 1.26.0-dev` 和 `onnxruntime-node: 1.24.3`，不再使用旧版 `onnxruntime-web: 1.14.0`
4. **API 兼容性**: 大部分 API（pipeline 初始化、模型加载等）保持兼容，但主版本升级（2.x -> 4.x）可能存在 breaking changes，需要逐项验证
5. **包体积变化**: 从 46.6 MB 降至 9.5 MB（优化显著）

### 安全状态

- 未发现已知安全漏洞
- 但该包已**停止维护**（最后一版发布于 2 年前），未来发现的安全问题将不会被修复

### 建议

| 优先级 | 操作 | 说明 |
|--------|------|------|
| 中 | 迁移至 `@huggingface/transformers` | 官方包持续维护，含性能改进和安全修复 |
| 风险 | **中等** | 主版本升级(2.x->4.x)涉及 breaking changes，需要充分测试 |

## 2. xlsx (SheetJS)

### 当前状态

| 项目 | 值 |
|------|-----|
| 当前版本 | `^0.18.5` |
| npm latest | `0.18.5`（已是 npm 上该包的最终版本） |
| 最后发布日期 | 2022-03-24 |
| 许可证 | Apache-2.0 |

### 版本分析

`xlsx@0.18.5` 是 npm 上该包的**最新且最终版本**，发布时间为 2022 年 3 月。此后 npm 上再无新版本发布。

### 安全漏洞

**已知漏洞**: **CVE-2023-30533**（原型链污染 / Prototype Pollution）

| 项目 | 详情 |
|------|------|
| CVE 编号 | CVE-2023-30533 |
| 类型 | Prototype Pollution |
| 严重程度 | **高** |
| 影响版本 | xlsx < 0.19.3 |
| 修复版本 | 0.19.3+ |

**关键问题**: 修复版本 `0.19.3` **从未在 npm 上发布**。SheetJS 团队将 `0.19.3` 及后续版本转移至了付费产品（SheetJS Pro），npm 上的社区版停留在 `0.18.5`，**该漏洞无法通过 npm 升级修复**。

### SheetJS 生态现状

- npm 上的 `sheetjs` 包（2.0.0）仅是一个占位符包，实际大小仅 1.4 KB，不可用
- 真正的 SheetJS 修复版本只在 SheetJS Pro（商业版）中提供
- 社区对此策略争议较大

### 替代方案

| 替代包 | 说明 | 活跃度 |
|--------|------|--------|
| `exceljs` | 功能全面的 Excel 读写库，支持 xlsx 格式 | 活跃维护 |
| `xlsx-populate` | 轻量级 xlsx 读写库 | 维护中 |
| SheetJS Pro (付费) | 原包的商业版本，含安全修复 | 活跃 |

### 建议

| 优先级 | 操作 | 说明 |
|--------|------|------|
| **高** | 评估安全风险 | CVE-2023-30533 为原型链污染漏洞，如果应用处理不可信的 Excel 文件输入，则风险较高 |
| **高** | 考虑替换为 `exceljs` | 这是社区推荐的替代方案，活跃维护且无已知高危漏洞 |
| 备选 | 限制输入来源 | 如果无法短期内替换，确保只处理可信来源的 Excel 文件 |
