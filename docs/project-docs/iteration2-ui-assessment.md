# 第二轮迭代 UI 评估报告

> 评估日期：2026-05-29
> 评估对象：AI Novel Workshop（/data/share/project/ai-novel-workshop/）
> 参考对象：InkOS Studio（/data/share/project/inkos/packages/studio/）

---

## 一、总体评估

经过第一轮完整开发和4轮UI优化迭代，系统整体UI质量已达到中上水平。Design Token体系完善，主题支持良好，组件风格统一。但与InkOS Studio相比，在以下方面仍有改进空间：视觉层次感、页面转场动效、信息密度控制、移动端适配深度。

---

## 二、逐项痛点分析

### 2.1 ProjectEditor 布局合理性

**现状**：
- Grid三栏布局（260px侧边栏 + 主内容 + 300px右侧栏），支持折叠/沉浸模式
- 侧边栏承载了12+个导航项（仪表盘、沙盘、章节、配置、Agent控制台、工具折叠组6项）
- Agent控制台在侧边栏出现了两次（Pipeline快速入口 + 工具折叠组内重复项，L140-149）

**问题**：
1. **导航项重复**：Agent控制台同时出现在"Pipeline快速入口"（L85-95）和"工具折叠组"（L140-149），造成困惑
2. **信息层级不清晰**：主功能（仪表盘/沙盘/章节/配置）与辅助工具（摘要/质量报告/Token用量）没有视觉权重区分
3. **侧边栏底部拥挤**：保存状态、快捷键、主题切换、返回4个功能紧密排列，保存状态指示器空间不足
4. **对比InkOS**：InkOS使用分组标题（"Books" / "System" / "Tools"）+ 大写字母间距标识，层级清晰

**优化方案**：
| 项 | 优化内容 | 优先级 |
|---|---------|-------|
| E-1 | 移除工具折叠组内重复的Agent控制台入口 | P0 |
| E-2 | 侧边栏分组增加小标题文字（核心功能 / 工具） | P1 |
| E-3 | 侧边栏底部改为横向排列的图标按钮组，节约垂直空间 | P2 |

### 2.2 Agent 控制台信息展示清晰度

**现状**：
- 6个Agent以卡片网格展示（`minmax(260px, 1fr)`），每个卡片包含：文字图标、名称、阶段、优先级、模型名、启用开关、操作按钮
- 底部有批量操作区（运行生成前/后Agent、停止全部）和执行日志

**问题**：
1. **文字图标辨识度低**：将emoji替换为"规划""执笔"等两字标识后，在小尺寸(24x24)圆角方块中文字拥挤，辨识度不如图标
2. **Agent卡片信息过载**：阶段、优先级、模式、模型名4项元信息在同一行wrapping，小屏下排版凌乱
3. **执行日志缺少视觉层次**：所有日志条目（running/success/failed）仅靠颜色区分，无图标差异化
4. **对比InkOS**：InkOS的聊天工具执行步骤使用专属Tool组件，状态切换有明确的icon动画（spinner→check→error）

**优化方案**：
| 项 | 优化内容 | 优先级 |
|---|---------|-------|
| A-1 | Agent图标改为SVG内联图标（规划→Compass、执笔→PenLine、巡检→Shield等） | P1 |
| A-2 | 元信息区改为两行网格布局，小屏下保持整齐 | P1 |
| A-3 | 执行日志增加状态图标（spinner/check/x-circle），与AgentConsole现有status-icon统一 | P2 |

### 2.3 Pipeline 进度面板视觉反馈

**现状**：
- WritingDashboard顶部新增Pipeline状态总览栏，显示3个状态项（AI模型/Agent流水线/续写进度）
- 使用8px圆点 + 文字标签 + el-tag 组合

**问题**：
1. **视觉存在感弱**：Pipeline状态栏使用`shadow="never"` + 左侧4px竖条，与下方metric卡片视觉权重相同，未突出"系统健康状态"的优先级
2. **状态不够动态**：Agent流水线状态始终显示"dot-success"（硬编码L35），未与实际Agent运行状态联动
3. **缺少进度可视化**：续写进度仅显示"x/y 章定稿"数字，未使用进度条等可视化元素
4. **对比InkOS**：InkOS Dashboard在书列表中为每本书实时显示写作进度条和状态标签

**优化方案**：
| 项 | 优化内容 | 优先级 |
|---|---------|-------|
| P-1 | Pipeline状态栏增加左侧渐变色条（绿→蓝），提升视觉存在感 | P1 |
| P-2 | Agent流水线状态从store获取实时运行状态（idle/running/error） | P1 |
| P-3 | 续写进度增加mini进度条（与章节状态卡片的进度条风格一致） | P2 |

### 2.4 写作仪表盘功能入口可达性

**现状**：
- Hero区：1个"打开章节管理"主按钮
- 快捷操作卡片：7个按钮（新建章节、一键续写、批量生成、章节管理、设定沙盘、Agent控制台、模型配置）
- Pipeline状态栏：1个"查看控制台"链接
- 继续写作卡片：1个"继续写作"按钮

**问题**：
1. **快捷操作卡片过长**：7个按钮纵向排列在8栏宽的卡片中，视觉上像菜单列表而非"快捷操作"
2. **核心操作不突出**："一键续写"是系统核心功能，但在快捷操作中排第2位且样式与其他按钮无差异
3. **守护进程控制位置偏**：守护进程面板占据了Dashboard Grid的第一个8栏位置（L86-145），但该功能使用频率低于章节状态和继续写作
4. **对比InkOS**：InkOS Dashboard为每本书直接提供"写下一章"主操作按钮，书列表上方是统计区域，信息层次分明

**优化方案**：
| 项 | 优化内容 | 优先级 |
|---|---------|-------|
| D-1 | 快捷操作改为2列网格按钮布局，减少纵向空间占用 | P1 |
| D-2 | "一键续写"按钮改为实心主色按钮（type="primary"），视觉突出 | P1 |
| D-3 | Dashboard Grid顺序调整为：章节状态 → 继续写作 → 守护进程，将高频功能前置 | P2 |
| D-4 | Hero区增加1-2个高频入口按钮（一键续写、设定沙盘） | P2 |

### 2.5 移动端/不同屏幕尺寸适配

**现状**：
- ProjectEditor：仅1处媒体查询（900px侧边栏折叠），无更小屏幕适配
- WritingDashboard：1处媒体查询（768px Hero纵向排列）
- AgentConsole：0处媒体查询
- SandboxLayout：2处媒体查询（1024px/768px）
- InkOS Studio：0处媒体查询（完全不适配移动端）

**问题**：
1. **AgentConsole无响应式**：`grid-template-columns: repeat(auto-fill, minmax(260px, 1fr))` 在窄屏下卡片自适应，但批量操作按钮可能溢出
2. **Pipeline状态栏未适配**：`flex-wrap: wrap` 能换行，但4项状态在小屏下分布不均匀
3. **守护进程面板布局固定**：daemon-stat的flex布局在极窄屏下标签和值会挤压
4. **与InkOS持平**：两者都不支持移动端，但InkOS的`max-w-4xl`居中布局天然限制了内容宽度

**优化方案**：
| 项 | 优化内容 | 优先级 |
|---|---------|-------|
| R-1 | AgentConsole增加768px断点：卡片改为单列，批量按钮改为纵向堆叠 | P2 |
| R-2 | Pipeline状态栏768px以下改为2x2网格布局 | P2 |
| R-3 | Dashboard快捷操作768px以下改为2列网格 | P3 |

## 三、与InkOS Studio的对比总结

| 维度 | AI Novel Workshop | InkOS Studio | 差距 |
|------|------------------|-------------|------|
| **视觉个性** | 科技风暗色系，系统字体栈 | 文学风暖色系，专用衬线字体+颗粒纹理 | InkOS胜 |
| **信息架构** | 二级路由+侧边栏12+项 | 扁平路由+分组侧边栏 | 各有优劣 |
| **组件一致性** | Element Plus + Design Token覆盖 | shadcn/ui原子化组件 | Workshop够用 |
| **AI交互体验** | Agent控制台（独立面板） | 对话流式渲染+工具步骤展示 | InkOS胜 |
| **动效质量** | 基础CSS动画 | CSS + motion库，丰富的微交互 | InkOS胜 |
| **响应式** | 3个断点，覆盖主要页面 | 无 | Workshop胜 |
| **无障碍** | aria标签+键盘快捷键系统 | 几乎无 | Workshop胜 |
| **可扩展性** | 插件系统+右侧面板 | 无 | Workshop胜 |
